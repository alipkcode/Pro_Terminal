# Code of Conduct

Pro Terminal aims to be a friendly, welcoming project for everyone, whatever their background,
identity or experience level.

## Expected behavior

- Be kind, patient and respectful, in issues, pull requests and discussions alike.
- Give and accept constructive feedback gracefully, and focus on what's best for the project.
- Assume good intent, and ask before assuming.

## Unacceptable behavior

- Harassment, insults, or discriminatory or sexualized language or imagery.
- Personal or political attacks, trolling, and deliberately disruptive behavior.
- Publishing other people's private information without their permission.

## Enforcement

Maintainers may edit or remove contributions, and temporarily or permanently ban anyone whose behavior
goes against this code. Report problems privately to the maintainer through
[GitHub](https://github.com/alipkcode). All reports are handled confidentially.

This code applies to all project spaces, and wherever someone represents the project.
